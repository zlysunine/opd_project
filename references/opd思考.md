# OPD 思考：文献核验、机制分析与研究选题 Prompt

> 使用方式：将下文整体作为研究讨论 prompt，并附上相关论文或链接。也可以保留“研究背景”和“回答原则”，每次只讨论一个问题模块。本文中的论文概括是我的初步理解，不代表已经核验的结论。

## 研究背景与任务

我正在研究大模型的 On-Policy Distillation（OPD）与 On-Policy Self-Distillation（OPSD），希望从已有论文的现象、局限和机制中提出值得验证的研究问题，进一步形成可以复现、实现和评估的研究方案。

请以熟悉大模型后训练、知识蒸馏和实验研究的研究者身份，帮助我审查下面的理解和疑问。我的目标是弄清楚：学生究竟学到了什么、蒸馏何时有效或失效，以及现有方法还存在哪些有证据支持的改进空间。

我已经学习过 PPO、DPO 和 OPD 的基本原理，但对梯度传播、概率分布、表征几何和部分理论推导仍需要逐步解释。请先给出清楚的结论，再解释机制和证据；必要时用简单例子和公式展开。

## 回答原则

1. **先核验前提，再回答问题。**如果我的论文概括、术语使用或推论不准确，请明确指出原表述的问题，给出更准确的表述及依据。不要为了认同我的观点而接受错误前提。
2. **区分证据层次。**明确标注哪些是论文报告的实验现象、哪些是作者的解释、哪些是理论证明，以及哪些只是你或我的研究假设。不要把相关性写成因果关系，也不要把特定实验设置的结果写成普遍规律。
3. **依据原始资料。**涉及具体论文、算法细节、性能数字和新颖性判断时，优先核对论文正文与官方代码，给出论文链接及相关章节、公式或图表位置。不要编造引用；未提供或无法确认的论文，尤其是仅有缩写的 OPRD，应说明缺失信息，不要猜测其方法。
4. **比较时控制条件。**说明模型、数据、监督来源、训练预算、生成长度与评估方式是否可比。涉及“更有效”“更强”“更稳定”等判断时，明确衡量标准。
5. **解释应服务于问题。**不要堆砌术语或罗列无关论文。涉及重要公式时，先定义符号，再说明它为何能回答当前问题；不能跳过决定结论的推导步骤。
6. **提出可证伪的研究建议。**每个建议都应包含机制假设、最小实验和失败判据。不要把“加入某个损失、权重或模块”直接等同于有价值的创新，也不要声称未经检索的方向尚无人研究。

## 二、损失计算在输出端，究竟更新了什么？

我曾把 OPD／OPSD 理解为通过逐 token 的反向 KL 训练，并因此疑惑：损失是在输出概率上计算的，是否意味着只更新最后的输出层？

请围绕以下问题展开：

1. 先核验“OPD／OPSD 都使用逐 token 反向 KL”这个概括是否过于宽泛，再区分损失计算的位置、梯度传播的路径和实际可训练的参数集合。
2. 分别解释全参数微调、只训练输出层，以及 LoRA／部分层微调时，蒸馏信号怎样影响模型。用一个最小计算图或链式法则示例说明。
3. 如果只更新输出层，哪些能力变化可能通过重新读取已有表征实现？哪些变化可能需要调整内部计算？请说明判断依据，避免把某种更新方式与“必然获得／无法获得推理能力”直接画等号。
4. 当教师和学生的参数量、层数、架构不同时，输出层面的蒸馏如何成立？模型容量、词表对应和优化难度分别造成什么限制？

## 三、自蒸馏没有引入新的外部知识，为什么还能提升？

无监督 OPSD 从模型自身生成的多个候选中提取伪监督。我的疑问是：如果没有引入外部知识，模型究竟是在获得新能力，还是把本来偶尔能做到的事情变得更稳定？

1. 请区分知识获取、已有能力的提取与重组、正确答案概率提高，以及推理策略或搜索效率改善。说明这些变化是否互斥，怎样进行操作化定义。
2. 同一个模型为何能通过多次采样、筛选或不同上下文形成更有用的教师信号？这种优势需要什么条件？在什么情况下会放大一致但错误的答案？
3. 对比无监督、半监督与有监督 OPSD 的效果时，如何计算标注成本、采样成本和训练成本？现有结果能够支持哪些结论，尚不足以支持哪些结论？
4. 持续迭代 OPSD 是否能持续提升？如果出现饱和或退化，如何区分教师信息不足、学生容量限制、探索减少、伪标签错误和优化问题？
5. SFT 与 OPSD 都可能利用参考答案，但分别怎样使用答案？请比较数据来自谁、训练时看到哪些前缀、监督是硬标签还是概率分布，以及学生推理时是否需要参考答案。不要只把差异概括为“答案放在输出还是 prompt”。

## 四、如何判断学到了推理能力，而不是记忆或捷径？

我关心：特权信息构造的教师，是否会让学生更自信，却减少纠错、验证和深度探索？学生的分数提高，又是否可能主要来自模板、答案提示或数据记忆？这些目前是疑问，不能直接当作事实。

请回答：

1. “教师的推理能力更强”应该体现在哪些可观测行为和指标上？答案正确率、生成多样性、错误恢复能力、问题难度适应性和分布外泛化分别能说明什么？
2. 如果训练后 wait、maybe 等标记更少，能否据此判断推理能力下降？如何排除表达风格变化、回答变短等混杂因素？
3. 如果 pass@1 提高而 pass@k 未提高或下降，应如何解释？如何在相同采样次数、温度、生成长度或总计算预算下进行比较？哪些情况表明概率重新分配，哪些证据才支持更广的解题能力变化？
4. 如何区分记忆、捷径学习与可迁移的推理能力？请提出针对题目改写、条件反转、组合泛化、难度外推、错误前缀恢复或参考信息扰动的实验，并解释每项实验排除了什么替代解释。
5. 请给出一套精简的评估方案。每个指标写明测量对象、计算方式或估计方式、支持的判断，以及不能单独推出的结论。不要假设一个指标就能完全证明“真正学会了推理”。

## 五、蒸馏的上限与慢收敛究竟来自哪里？

我原先认为，蒸馏就是通过教师指导，让学生在自身架构和容量约束下尽可能提高能力。如果更强的教师并不总是更有效，是否意味着学习效果还受到师生兼容性、状态分布和优化路径的限制？

请结合两篇 Rethinking OPD 论文分析：

1. 区分教师的任务能力、对当前学生的可教性、师生分布的可匹配程度，以及训练过程是否能有效逼近目标。为什么它们可能不一致？
2. “已经达到最佳状态”应如何定义？请区分蒸馏目标的最优值、给定预算下的最好结果，以及目标任务上的泛化表现。哪些可以通过实验近似判断，哪些不能轻易声称？
3. 一个 query 的 rollout 为什么可能覆盖许多问题涉及的状态类型？聚类覆盖率相近是否意味着监督信息、能力覆盖或训练难度也相同？
4. 单个 query 训练数百步仍能提升，是否真的意味着全数据训练会“先从第一道题学到很多，后面的题贡献越来越少”？请先检查实际训练是否逐题顺序进行，以及这个推论是否成立，再给出替代解释。
5. 如何区分新 query 带来的信息增量、已有状态被再次优化的收益，以及训练后期吸收率下降？请设计固定训练步数、固定总生成 token 或固定教师调用预算的对照实验，说明各自控制了什么。
6. “数据过量、算法不足”是否足以推出优化空间很大？请解释还需要哪些证据，以及怎样定位瓶颈来自梯度估计、目标函数、轨迹分布、更新策略或模型容量。

## 六、表征对齐是否等于能力对齐？

我的直觉是：学生应该在自己的架构中找到有效的计算方式，不一定需要复制教师的内部表征。因此，我想审查“让某些层的向量更相似，就能更好地获得教师能力”这一假设。

1. 在核对 OPRD 的实际方法后，解释为什么选择相应的表征损失。向量差值、余弦距离、分布匹配或关系结构匹配，各自保留和约束了什么？
2. 不同模型的表征坐标系是否天然可比？如果两个模型具有相似功能，但内部表征经历了旋转、缩放或基变换，直接匹配向量可能出现什么问题？请给出简单例子。
3. 当维度不同时，投影或适配器能否无损对齐？这取决于哪些条件？即使投影后的距离很小，能否说明教师的重要信息已经被学生使用？
4. 不同深度、架构和参数量的模型，应如何确定可比较的层与 token 位置？强制匹配是否可能限制学生形成适合自身容量的表征？
5. 请分析方向、范数、子空间和表征间关系各自可能承载的信息。使用球面建模、旋转或 vMF 分布，需要怎样的数据性质和实验证据？不要默认“方向重要”就意味着“范数无用”。
6. 如何验证表征损失确实改善了推理，而不只是让一个几何指标变好？请设计输出蒸馏、表征蒸馏、两者结合及必要控制组的比较，说明如何控制额外参数和训练成本。

## 七、把这些疑问转化为下一步研究

综合以上分析，请提出最多三个值得优先验证的研究方向，并明确你的首选。方向应来自尚未解释清楚的现象或已有方法的具体失效条件，不要仅仅组合热门技术。

每个方向请包含：

- **研究问题与动机：**具体要解决什么，为什么有意义？
- **可证伪的机制假设：**什么现象支持它，什么结果会推翻它？
- **与已有工作的关系：**最接近哪些论文，已有方法做到哪里，拟研究的差异在哪里？没有核验的新颖性必须标明。
- **最小实验：**需要什么模型、数据、基线、干预和指标？优先验证现象，再决定是否开发新算法。
- **关键混杂因素：**如何排除数据泄漏、额外计算、生成长度、模型规模和提示信息差异等解释？
- **继续或停止的标准：**出现什么结果值得投入，出现什么结果应调整或放弃？
- **实施成本：**列出主要计算开销和可缩减的设置；在不知道我的硬件条件时，不要给出没有依据的精确显存或耗时。

请给出一个先做什么、后做什么的短期执行顺序。避免把所有方向同时展开；优先推荐能以较低成本验证关键假设、且结果无论正负都能帮助后续决策的实验。
